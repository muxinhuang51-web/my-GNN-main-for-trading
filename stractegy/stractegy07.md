```markdown
# LLM 驱动的边更新与构建：执行文档（含一手可信数据源）

## 1. 背景与动机
当前异构图包含三类边：`same_industry`（静态行业）、`same_concept`（概念板块）、`high_corr`（动态收益率相关）。这些边受限于：
- **行业分类滞后且粗粒度**：申万一级仅 31 类，大量跨行业关联被忽略。
- **概念板块依赖人工维护**，无法及时反映新兴主题。
- **相关性边仅捕捉价格联动**，缺乏对底层经济联系（供应链、技术合作、竞争）的直接刻画。

引入 **LLM（大语言模型）** 可从海量金融文本中提取更深层、更动态的股票关联，构建/更新图边，使图结构更贴近真实的信息传播网络。

## 2. 目标
- 构建 **LLM 驱动的静态边**：基于公司业务描述、年报等长文本，生成业务相似度边、供应链关系边等。
- 构建 **LLM 驱动的动态边**：每日/周从新闻、公告中抽取实体关系，更新情绪共现边、事件关联边。
- 将新边无缝接入现有 `HeteroData`，重新训练 RGCN，并在回测中验证提升。

## 3. 数据源选型（一手、可信、非社媒）
本方案仅采用权威发布的一手数据源，杜绝社媒噪音，保证数据质量和可追溯性。

| 数据源 | 类型 | 说明 | 用途 | 获取方式 |
|--------|------|------|------|----------|
| 巨潮资讯网 | 公告原文 | 证监会指定披露平台，所有A股年报/半年报/季报、重大合同、关联交易公告 | 业务描述提取、供应链关系抽取 | 免费PDF下载，或通过聚源/Wind批量获取 |
| 上市公司年报（MD&A） | 定期报告 | “管理层讨论与分析”章节，含经营分析、行业格局、核心竞争力 | 生成 `business_sim` 边 | Wind/同花顺/聚源文本数据库 |
| 中国证券报、上海证券报、证券时报、证券日报 | 财经新闻 | 官方媒体，权威政策解读、公司新闻 | `news_co_occur` 边，情绪分析 | 报纸电子版、Wind新闻、同花顺iFinD |
| 财联社 | 实时新闻 | 速讯类新闻，覆盖A股事件、公告速递 | `news_co_occur` 边（日频） | 数据接口采购或爬虫 |
| 深交所/上交所互动易、e互动 | 投资者关系 | 公司官方回复，常有供应链、客户、技术合作细节 | 补充供应链及合作边 | 网站公开，可爬取 |
| 国家知识产权局专利数据库 | 专利 | 发明、实用新型专利，可用于技术相似度 | `technology_sim` 边 | 免费检索，或采购智慧芽等商业库 |
| 万得（Wind）供应链数据库 | 结构化数据 | 前五大客户/供应商数据，可直接建边 | `supply_chain` 边 | 采购万得终端或数据接口 |
| 央行、统计局、工信部 | 宏观/产业政策 | 政策文件、产业规划 | 事件关联边（跨行业影响） | 政府网站公开 |

**核心原则**：所有文本均来自一级信源（官方披露、持牌媒体、官方互动平台），确保可复现和可信度。

## 4. 边类型设计
| 新边类型 | 方向 | 含义 | 主要数据源 | 更新频率 |
|----------|------|------|----------|----------|
| `business_sim` | 无向 | 业务描述语义相似度（Top-K） | 年报“公司业务概要” / MD&A | 季度 |
| `supply_chain` | 有向 | 供应链关系（客户/供应商） | 年报前五大、互动易、Wind供应链 | 季度 |
| `tech_collab` | 无向 | 技术合作、共同研发等 | 公告（合作协议）、互动易 | 不定期 |
| `news_co_occur` | 无向 | 新闻共同提及（短期关联） | 四大报、财联社 | 日频 |
| `sentiment_spillover` | 有向 | 新闻情绪从A传导至B（时间序列） | 四大报、财联社（需时序） | 日频 |

**第一版优先落地**：`business_sim` + `news_co_occur`（成本低，数据易得）。

## 5. 技术选型
- **长文本语义建模**：使用本地可部署的金融领域预训练模型 `mengzi-bert-base-fin` 或 `FinBERT-Chinese`，从年报/公告提取嵌入向量。
- **关系抽取**：采用 Few-shot Prompt + 开源大模型（如 `Qwen-72B` 或 `DeepSeek-V3`）从公告/互动易文本中抽取三元组（公司A，关系，公司B）。成本允许时可调用 GPT-4o API。
- **新闻实时处理**：每日通过财联社或Wind新闻接口拉取文本，用正则/NER识别股票代码，统计共现频次。
- **实体链接**：构建公司全称-简称-代码映射表，解决同一公司多种称呼问题。

## 6. 实施步骤
### 6.1 阶段一：静态业务相似边 `business_sim`（约4小时）
#### a. 数据获取
- 从Wind/同花顺导出最近一期年报的“公司业务概要”或“管理层讨论与分析”文本，确保覆盖全A股。
- 缺失文本用招股说明书或最新半年报补齐。

#### b. 嵌入生成
```python
from transformers import AutoTokenizer, AutoModel
tokenizer = AutoTokenizer.from_pretrained("mengzi-bert-base-fin")
model = AutoModel.from_pretrained("mengzi-bert-base-fin").to("cuda")

def get_embedding(text):
    inputs = tokenizer(text, return_tensors="pt", truncation=True, max_length=512).to("cuda")
    with torch.no_grad():
        outputs = model(**inputs)
    return outputs.last_hidden_state[:,0,:].cpu().numpy()[0]
```

#### c. 相似度矩阵与边构建
- 计算余弦相似度矩阵，每只股票保留相似度最高的 K=10 个邻居。
- 生成无向边（或双向边），可选边权重为相似度。

#### d. 集成入图
- 将新边加入 `HeteroData`，更新 `edge_type_dict`。

### 6.2 阶段二：动态新闻共现边 `news_co_occur`（约5小时）
#### a. 新闻数据管道
- 每日通过API获取四大报/财联社新闻（标题+正文），提取发布时间。
- 使用公司名称词典匹配文中提及的股票，生成股票列表。
- 统计当日任意两股在同一新闻中的共现次数（可跨新闻累计）。

#### b. 建边
- 取共现次数>=2的对，或每只股票Top-15共现邻居。
- 权重为当日共现次数或归一化值。

#### c. 日频更新
- 每日收盘后生成当日共现边，替换旧边。

### 6.3 阶段三：供应链/关系抽取边（可选）
- 从年报“前五大客户/供应商”段落，或互动易相关问答，用LLM抽取结构化关系（`company_A – supplier_of – company_B`）。
- 汇总成有向边，定期更新（如按季度）。

## 7. 模型与训练适配
- 新增边类型后，`num_relations` 从3调整为实际总数。
- 训练：可选择在原有权重基础上微调，或从头训练。
- 验证：通过消融实验，对比加入每条新边前后的 IC、夏普、分组收益。

## 10. 风险控制
- **实体链接错误**：建立严格的公司名称映射表，并人工抽查。
- **文本缺失**：约5%股票缺业务描述，用招股说明书或官网文字补充；如仍无，不构建该股的 `business_sim` 边。
- **新闻版权与合规**：使用数据库授权接口，避免无授权爬取。
- **LLM调用成本**：嵌入生成优先使用本地模型；关系抽取采用开源大模型本地部署或低频调用云端API。
